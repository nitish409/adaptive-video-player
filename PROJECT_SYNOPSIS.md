## 3. PROJECT DESCRIPTION
This project is a frontend-only video-streaming website developed using HTML, CSS and JavaScript. Designed on the lines of popular platforms like Netflix, it is implemented as a 10-page website that demonstrates how a real streaming service looks and behaves at the frontend level.

Users can browse categorized content through horizontal rows, select videos, and play them in an HTML5-based player. The player clearly indicates loading, playing, paused and buffering states, and demonstrates simulated automatic quality switching (e.g., 480p, 720p, 1080p) without requiring a real streaming server. Locked-content icons represent premium-protected videos, while keyboard and arrow-key navigation provides TV remote-style interaction.

All videos, thumbnails and metadata are served from a bundled local catalog rather than a live server. The interface uses visible status indicators, quality information and responsive controls to make playback behaviour easy to understand. This approach provides a lightweight and practical demonstration of video-player state management, content browsing and responsive interaction.
